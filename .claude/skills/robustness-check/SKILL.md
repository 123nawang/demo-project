# Skill：DID 稳健性检验

## 触发条件
当你需要对一个面板数据中的处理效应做稳健性检验时，调用此 Skill。适用于：DID、事件研究、安慰剂检验、异质性检验和机制检验。

## 背景知识
- 处理变量 D：个体是否受到处理。
- 结果变量 y：要解释的结果变量。
- 个体维度 id：企业/地区/个体标识。
- 时间维度 t：时间变量。
- 平行趋势：处理组和对照组在处理前趋势相似。
- 稳健性检验：用于验证主结论是否高度依赖某一设定。

## 工作步骤
1. 先读取 README、代码注释或数据字典，识别 y、D、id、t、控制变量和聚类层级。
2. 复现主回归，确认固定效应与聚类层级。
3. 按顺序做稳健性检验：R1–R7、T1–T4。
4. 对每一项输出：Prompt、结果文件、观察。
5. 汇总到 robustness_summary.md。
6. 判定主结果是否稳定，并说明残余威胁。

## 检查清单
- 是否先识别变量，再跑模型？
- 是否保留固定效应与聚类层级？
- 是否检查处理前趋势？
- 是否避免虚构政策背景和文献？
- 是否输出 Prompt 与结果文件？
- 是否在汇总时区分“统计显著”和“因果效应”？

## 边界条件
- 不允许虚构真实政策和真实证据。
- 不允许修改原始数据文件。
- 不允许直接在没有证据的情况下写出因果结论。
- 不允许在缺失输入时强行推断。

## 验证方式
- 检查系数方向与主回归是否一致。
- 检查事件研究处理前系数是否基本平坦。
- 检查安慰剂结果是否集中在 0 附近。
- 检查汇总表是否包含结论、观察和判断。

## 如何迁移
如果换到“最低工资对就业”“医保对健康”等研究主题，只需替换变量名和研究机制，不需要重写核心设计：
- y：就业率、健康指数等。
- D：政策处理变量。
- id：州、地区、企业。
- t：年度/季度。
- 固定效应：地区/年份固定效应。
- 聚类层级：地区、行业或个体。

核心逻辑不变：先识别变量→主回归→稳健性检验→汇总评估。
