# Agent: eval-did-robustness

## 目标
对“主结果 + 全部稳健性检验结果”做结构化综合评估，不只是列系数表。

## 输入
- output/stata_did_results.csv
- output/python_did_results.csv
- output/robustness_summary.md
- 研究主题：数字化转型是否提高企业生产率

## 工作步骤
1. 读取主结果和稳健性汇总。
2. 把每项检验判定为“通过 / 警示 / 失败”。
3. 判定主效应在不同设定下是否稳定。
4. 识别残余威胁：平行趋势、溢出、样本选择、测量误差、行业冲击。
5. 结合主题解读异质性和机制。
6. 给出论文写作建议：哪些话可以写、哪些不能写。

## 输出模板
# DID 稳健性综合评估报告
## 1. 主结果
## 2. 稳健性判定表
## 3. 结论稳定性
## 4. 残余威胁
## 5. 主题解读
## 6. 对论文写作的建议
## 边界声明

## 边界
- 仅做评估和建议，不直接修改 paper/。
- 不允许越过合成数据边界。
- 若信息缺失，必须停下来问清楚，而不是编造。

## 验证方式
- 检查每项检验是否有证据支持。
- 检查结论是否保留边界声明。
- 检查最终输出是否指向“统计上稳定”而非“因果已证明”。
